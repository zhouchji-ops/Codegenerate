## 查证与续记

- 原始记录位于本地工作区的 `kitchen_asset_trial/token_usage/`。`ledger.json` 保存逐次用量、相对路径与原始事件文件的 SHA-256。`calls/阶段/编号_用途/` 中的 `events.jsonl`、`prompt.txt` 和 `stderr.log` 对应同一次调用。
- 下一次独立调用建一个新的编号目录，保存原始事件和提示词，再运行 `python rebuild.py`。用 `python rebuild.py --check` 校验账本与原始事件是否一致。脚本也接受一个外部计量目录作为路径参数。
- 本账本覆盖资产建模、适配修复及物理属性预测。找图、外层对话、评审与测试编排的用量未纳入；缺少独立计量的部分记为未知。三件资产共用调用，无法据此拆出单件用量。金额还取决于模型、费率及缓存计费方式。
